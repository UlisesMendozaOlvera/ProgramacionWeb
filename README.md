# Proyecto de Programación Web

Este proyecto es una aplicación web desarrollada por Bryan Ulises Mendoza Olvera que incluye varias páginas HTML con diferentes funcionalidades y estilos modernos.

## 📋 Descripción

El proyecto consiste en un sitio web con múltiples páginas que incluyen:
- Página principal (index.html)
- Sección de categorías
- Galería de fotos
- Página de contacto
- Sección "Acerca de nosotros"
- Página de componentes

## 🚀 Tecnologías Utilizadas

- HTML5
- CSS3
- JavaScript
- Bootstrap 4.5.2
- jQuery 3.5.1
- SASS/SCSS
- LESS

## ⚙️ Requisitos Previos

- Node.js
- npm (Node Package Manager)

## 🛠️ Instalación

1. Clona el repositorio:
   ```bash
   git clone https://github.com/Sumtrack98/ProgramacionWeb.git
   ```

2. Instala las dependencias:
   ```bash
   npm install
   ```

## 📦 Scripts Disponibles

- `npm run dev`: Inicia el servidor de desarrollo (lite-server)
- `npm run scss`: Compila los archivos SCSS a CSS
- `npm run less`: Compila los archivos LESS a CSS
